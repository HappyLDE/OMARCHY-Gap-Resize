# Community plugin submission

- Plugin ID: `io.github.leosilver.gap-resize`
- Category: Desktop
- Tags: `hyprland`, `quickshell`, `workspaces`
- Runtime network access: none
- Runtime privilege escalation: none
- Runtime data collection: none

The plugin uses a Quickshell overlay with exact gap-shaped input regions and
local `hyprctl` commands for relative window resizing. It disables Hyprland's
broad native border-resize interaction while active so window borders remain
click-through. It does not modify Hyprland configuration files, access the
network, collect data, or require elevated privileges.
